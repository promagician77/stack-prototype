Interstitials never show in the first game or right after a rewarded ad. Buttons on ad and store screens ignore taps for 0.7 s, so a fast-tapping player never hits an ad by accident. Buy remove-ads, then and restore.

    Every bug report is reproducible

    A run is a seed plus the tick of each tap. Send that, and I replay the exact game that broke, on any device.

    Browser and Unity are the same game

    The same seed and inputs give the same tower hash in C# and JavaScript, checked by tests on both sides.

    Smooth on cheap Android

    Fixed-step rules, pooled objects, and quality that drops by itself when frames run long, then recovers.

    Tune without a new build

    Speed, perfect window, and ad frequency come from config. A client's "make it easier" is a value, not a release.
